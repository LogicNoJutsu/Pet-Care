Settings & Sync
🔄 GitHub Gist Auto-Sync
Auto-saves to a private GitHub Gist on every change. Share across devices with the same token + Gist ID.
Setup: github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new → tick gist only → copy token (ghp_...)
Use classic token · tick gist scope · no expiry recommended
📧 Email Reminders (EmailJS)
Reminders for refills, appointments, vaccinations, insurance, and PUC expiry. Free up to 200/month.
emailjs.com setup: Add Email Service → Create Template with variables: {{member_name}} {{record_name}} {{due_date}} {{days_left}} {{reminder_type}} {{to_email}}
🔔 Browser Push Notifications
Popup reminders on your device when app is open. Android Chrome works best. iPhone: Add to Home Screen first.
