🔄 GitHub Gist Auto-Sync
Your data auto-saves to a private GitHub Gist every time you make a change. Anyone with the same token and Gist ID can access the same records from any device.
One-time GitHub setup:
1. Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Click "Generate new token (classic)"
3. Give it a name, tick the gist checkbox only
4. Copy the token (starts with ghp_) and paste below
5. Leave Gist ID blank — it will be created automatically on first save
⚠️ If sync fails, check:
• Token expired → generate a new one at github.com
• Wrong scope → must have gist ticked (not just repo)
• Extra spaces in token → paste carefully
• Must use classic token, not fine-grained
📧 Email Reminders via EmailJS
Receive email reminders at 15 days, 7 days, and 1 day before any vaccination or deworming is due. Free — up to 200 emails/month.
One-time EmailJS setup (free at emailjs.com):
1. Sign up at emailjs.com and add a Gmail/Outlook service
2. Create an Email Template with subject like "PawCare Reminder" and body using:
  {{dog_name}} — pet name
  {{record_name}} — vaccine/medicine name
  {{due_date}} — due date
  {{days_left}} — days remaining
  {{to_email}} — recipient (set as To field)
3. Copy your Public Key, Service ID, and Template ID below
